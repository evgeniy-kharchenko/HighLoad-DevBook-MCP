# Проведение демо

1. Подготовьте две отдельные рабочие копии одного исходного состояния. Для каждого прогона откройте новую сессию агента.
2. Зафиксируйте модель и её настройки, версию агента, доступные инструменты и лимит времени. Подготовьте одинаковые условия работы с GitLab API для обоих прогонов.
3. Возьмите текст из [PROMPT.md](PROMPT.md) и допишите сразу после него полный текст [SPEC.md](SPEC.md). Отправьте одинаковое сообщение в обе сессии.
4. В первом прогоне отключите DevBook MCP. Во втором подключите DevBook MCP и зафиксируйте версию доступных стандартов. Сохраните одинаковые настройки остальных инструментов.
5. Сохраните изменения, результаты проверок и сведения о стандартах, к которым обратился агент. Зафиксируйте все ручные вмешательства и повторные попытки.

## Сравнение

Запустите одинаковые проверки в обеих копиях. Оцените полноту API, хранение данных, синхронизацию с GitLab, обработку ошибок, настройку сервиса, тесты и соответствие выбранным инженерным стандартам. Для каждого наблюдения приведите пример из кода, результат проверки или ссылку на конкретный стандарт.

Одна пара прогонов иллюстрирует возможный эффект инженерного контекста. Для оценки воспроизводимости повторите эксперимент с теми же условиями.
