# Сообщения об уязвимостях

Отправьте подробности владельцу репозитория приватно. Если в разделе Security доступна кнопка Report a vulnerability, используйте её. Для первого контакта через публичный issue достаточно попросить владельца указать приватный канал связи.

В приватном сообщении укажите затронутый коммит, условия возникновения проблемы и возможное влияние. Исключите токены, ключи и персональные данные из примеров.
