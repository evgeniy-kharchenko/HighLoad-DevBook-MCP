# Промпт для запуска демо

Реализуй задачу по спецификации ниже.

Сначала изучи существующий проект, его структуру и доступные инженерные стандарты.

После этого реализуй задачу целиком.

Не ограничивайся описанием решения. Создай необходимые файлы, реализуй функциональность, добавь тесты и проверь результат.

Технические решения, которые явно не определены в спецификации, принимай самостоятельно с учетом доступных инженерных стандартов проекта.
