# Промпт для запуска

Реализуй задачу по `SPEC.md`. Если текст спецификации приложен к сообщению, используй приложенный текст.

Сначала изучи существующий проект, его структуру и доступные инженерные стандарты.

После этого реализуй задачу целиком.

Размещай весь проект в рабочей директории, указанной в стартовом сообщении. Если она не указана, используй текущую рабочую директорию. Создавай исходный код, тесты, файлы зависимостей и конфигурации внутри неё.

Не ограничивайся описанием решения. Создай необходимые файлы, реализуй функциональность, добавь тесты и проверь результат.

Технические решения, которые явно не определены в спецификации, принимай самостоятельно с учетом доступных инженерных стандартов проекта.

С начала работы фиксируй этапы, обращения к инструментам и доступные данные о расходе токенов и времени. После реализации и проверок создай в корне рабочего проекта `RUN_REPORT.md` по разделу «Отчёт о выполнении» спецификации. Укажи расход по этапам, итоговые затраты и их источники, а также чего хватило и чего не хватало для выполнения задачи. Отдельно обозначь оценки и недоступные данные.
