# HighLoad DevBook MCP

Материалы мастер-класса HighLoad 2026 о том, как инженерные стандарты влияют на код, который генерирует AI-агент. В обоих прогонах агент получает одну спецификацию, один промпт и использует одну модель. Во втором прогоне он также получает доступ к инженерным стандартам через DevBook MCP.

## Структура репозитория

```text
HighLoad-DevBook-MCP/
├── without-devbook/  # Код, тесты и файлы проекта из прогона без DevBook MCP
├── with-devbook/     # Код, тесты и файлы проекта из прогона с DevBook MCP
├── PROMPT.md        # Общий промпт
├── SPEC.md          # Общая спецификация задачи
└── DEMO.md          # Запуск и сравнение прогонов
```

Обе директории для кода начинаются с пустого шаблона. Агент сам выбирает структуру Python-проекта. Для прогона без DevBook MCP используйте [стартовый промпт для `without-devbook/`](DEMO.md#запуск-в-without-devbook). Чтобы запустить генерацию прямо в `with-devbook/`, откройте корень репозитория, подключите DevBook MCP и скопируйте [стартовый промпт из DEMO.md](DEMO.md#запуск-в-with-devbook).
