# Отчёт о выполнении GitLab Project Registry

- Режим прогона — **с DevBook MCP**. Сервер ответил на 6 поисковых запросов и вернул 12 полных документов до генерации кода.
- Модель — `gpt-6.2-sol`, режим рассуждения `medium`. Клиент Codex CLI `0.171.0`, провайдер `gateway_ai`. Источник — `session_meta` и `turn_context` локального журнала сессии.
- Базовый коммит — `73c4424`. Приложение, тесты, миграции и отчёт созданы в `with-devbook/`. На старте в индексе уже было удаление `with-devbook/.gitkeep`.
- Среда проверок — macOS, Python 3.12.7, SQLite 3.45.3. Версии зависимостей зафиксированы в [uv.lock](uv.lock).

## Результаты проверок

| Проверка из `with-devbook/` | Результат |
| --- | --- |
| `pytest --basetemp=.checks/pytest -q -x` | **31 тест прошёл**, 1 предупреждение о deprecated-интеграции Starlette TestClient с HTTPX |
| `ruff check .` | Ошибок нет |
| `black --check .` | 28 файлов соответствуют форматированию |
| `mypy registry alembic` | Ошибок в 25 файлах нет |
| `alembic upgrade head → downgrade base → upgrade head → check` | Успешно на отдельной SQLite БД. Отличий от ORM-модели нет |
| Проверка сгенерированного OpenAPI | Все 6 операций, частичный PATCH с корректной схемой обязательности и публичные поля ответа |
| `uv sync --locked --offline` | Lock-файл актуален, 39 установленных пакетов проверены. Источник внешних пакетов — PyPI |

Проверки API проходят через FastAPI, DI-контейнер, слой сценариев, SQLAlchemy и файловую SQLite с миграциями. Покрыты CRUD, сохранение между экземплярами приложения, конфликт GitLab ID, успешная синхронизация, ошибки и таймаут GitLab. Тесты конкурентного PATCH и DELETE проверяют, что ответ GitLab, полученный по старому снимку, не перезаписывает более позднее изменение.

В ходе прогона путь для временных БД тестов перенесён в локальную `.checks/` и создан его родительский каталог. Статические проверки выявили замечания к типам и импортам. При первом запуске Alembic выявилась отсутствующая зависимость асинхронного SQLAlchemy, после чего добавлен extra `sqlalchemy[asyncio]` и пересобран lock-файл. Настроенное зеркало пакетов сначала не разрешалось по DNS и позднее влияло на выбор источника зависимостей. Зависимости получены с PyPI в вызове без локальных переопределений индексов.

## Применённые стандарты DevBook

Идентификаторы ниже — стабильные пути документов DevBook, возвращённые MCP. Номер редакции сервером не предоставлен.

| Документы | Влияние на техническое решение |
| --- | --- |
| `architecture/architectural-agreements`, `development/recommended-repository-layout-minimal` | Слои `api`, `services`, `domain`, `adapters` и `database` разделены. HTTP DTO и доменная модель независимы. Схема изменяется через Alembic, миграция лежит в `alembic/versions/`. |
| `architecture/di-and-wiring`, `architecture/adapters` | [Точка сборки](registry/containers/wiring.py) создаёт изолированный контейнер на lifespan приложения. Сервис получает фабрику UoW и адаптер GitLab, адаптеру внедряется HTTP-клиент. Выбран `dependency-injector` из списка согласованных пакетов для отдельного экземпляра контейнера и ресурсов у каждого приложения. Документ DI отдаёт предпочтение `that-depends`. |
| `development/uow-and-repositories` | Сервис создаёт один [Unit of Work](registry/database/uow.py) на сценарий и явно вызывает commit после записи. Закрытие сессии освобождает незавершённую транзакцию. Sync освобождает транзакцию чтения до запроса к GitLab и сохраняет данные с проверкой ревизии строки. Проверка защищает от конкурентных изменений. |
| `development/konfiguratsiya-servisa` | [Единый Settings](registry/settings.py) на старте приложения, переменные окружения и `.env`, токен хранится в `SecretStr` без значения по умолчанию. Тесты передают отдельные явные настройки. |
| `development/model-errors`, `development/api-naming` | [Централизованные обработчики](registry/api/errors.py) возвращают `code`, `message`, `details` со стабильными кодами. Внешние тела ответов и исключения преобразуются в безопасные сообщения. Использовано имя ресурса во множественном числе. Явные маршруты и поля `snake_case` из SPEC имеют приоритет над рекомендациями DevBook о RPC, префиксе версии и `camelCase`. Формат специализированного документа «Модель ошибок» выбран при расхождении примеров. |
| `development/resilience` | У [вызова GitLab](registry/adapters/gitlab/gitlab_adapter.py) явные таймауты HTTPX и общий бюджет времени. Для синхронного по контракту API-запроса выполняется одна попытка. Таймаут получает отдельный код и пишется предупреждение с машинным кодом в log record. |
| `development/zafiksirovannye-pakety-python`, `development/new-microservice-checklist` | FastAPI, Uvicorn, Pydantic Settings, SQLAlchemy, Alembic и HTTPX выбраны из списка. Для проверок использованы pytest, Ruff, Black и mypy. OpenAPI и примеры в README описывают контракт. |
| `development/testing-strategy` | [Тесты API](tests/api/) проверяют коды, контракты, успешные сценарии и ошибки. Фикстуры общие, однотипные кейсы параметризованы. Контур базы данных реальный, ответы GitLab подставляются через `httpx.MockTransport`. |

Сумма входных и выходных — **2 892 845 токенов**. Записано токенов записи кэша — 0.

Источник — события `token_count.info.total_token_usage` из `~/.codex/sessions/…/rollout-*.jsonl`. Последний доступный счётчик — 06:53:11 UTC. Токены по этапам — оценка распределения по разности накопительных счётчиков на границах этапов. Счётчики включают повторный контекст, в том числе результаты инструментов при последующих вызовах модели. Время по UTC включает ожидание команд и загрузки. Вызовы в таблице — верхнеуровневые обращения к инструментам из журнала. Пакетные подзапросы внутри одного обращения отдельно приведены для DevBook.

Итог включает зарегистрированную к моменту записи часть подготовки отчёта. Последующие проверка файла и финальный ответ в снимок не входят.

## Чего хватило и чего не хватало

| Условие | Решение и влияние на результат |
| --- | --- |
| PROMPT и SPEC описали цель, сущность, маршруты и поля синхронизации | Этого хватило для реализации всех операций и создания OpenAPI. Корневой README и DEMO описали расположение прогона. Во время обзора были прочитаны README и pyproject соседнего прогона. Его исходный код и тесты не использовались. |
| DevBook дал примеры UoW, DI, конфигурации и формата ошибок | Примеры определили границы слоёв, отдельную транзакцию записи при sync и единый HTTP-контракт ошибок. На этапе проверки тестовые инструменты подтвердили контракты, типы и миграцию. |
| SPEC оставляет открытыми выбор БД, правила PATCH и уникальность GitLab ID | Выбрана файловая SQLite для небольшого односервисного реестра. GitLab ID уникален и редактируем, PATCH сохраняет пропущенные поля, `default_branch` допускает `null`, листинг возвращает весь список по локальному ID. Согласованные примеры запросов и ожидаемый объём данных устранили бы эти допущения. |
| Не были предоставлены тестовый проект GitLab и токен | HTTP-заглушки проверяют URL, заголовок, ответ, ошибки и общий таймаут. Стенд с временным проектом и токеном нужен для проверки реальной аутентификации и сетевого окружения. |
| Docker Compose не использовался | Тесты запущены локально в изолированной `.venv` с файловой SQLite. Доступная в окружении команда Podman была ограничена sandbox при обращении к lock-файлу VM. Контейнерная проверка требует доступного runtime. |
| Производственные требования к нагрузке, трассировке и развертыванию не заданы | Для небольшого сервиса выбраны одиночная попытка sync, стандартное логирование и явная миграция перед запуском. Трейсинг, метрики, circuit breaker и проверку под реальной нагрузкой можно определить по требованиям целевого окружения. |
| Starlette TestClient предупреждает о совместимости с HTTPX | Предупреждение относится к тестовому клиенту. 31 тест проходит с зафиксированными зависимостями. Для удаления предупреждения потребуется обновить тестовый транспорт. |
| Нет счетов, публичного тарифа этого режима или версии пакета стандартов | Использованы счётчики локального журнала и идентификаторы документов. Для сверки стоимости и воспроизводимости нужны данные биллинга и версия набора DevBook. |

Команды запуска и примеры запросов приведены в [README.md](README.md).
