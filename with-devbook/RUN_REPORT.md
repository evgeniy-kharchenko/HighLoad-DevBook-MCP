# Отчёт о выполнении GitLab Project Registry

- Режим прогона — **с DevBook MCP**. Сервер ответил на 6 поисковых запросов и вернул 12 полных документов до генерации кода.
- Модель — `gpt-6.2-sol`, режим рассуждения `medium`. Клиент Codex CLI `0.171.0`, провайдер `gateway_ai`. Источник — `session_meta` и `turn_context` локального журнала сессии.
- Базовый коммит — `73c4424`. Приложение, тесты, миграции и отчёт созданы в `with-devbook/`. На старте в индексе уже было удаление `with-devbook/.gitkeep`.
- Среда проверок — macOS, Python 3.12.7, SQLite 3.45.3. Версии зависимостей зафиксированы в [uv.lock](uv.lock).

## Результаты проверок

| Проверка из `with-devbook/`                                    | Результат                                                                                  |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `pytest --basetemp=.checks/pytest -q -x`                       | **31 тест прошёл**, 1 предупреждение о deprecated-интеграции Starlette TestClient с HTTPX  |
| `ruff check .`                                                 | Ошибок нет                                                                                 |
| `black --check .`                                              | 28 файлов соответствуют форматированию                                                     |
| `mypy registry alembic`                                        | Ошибок в 25 файлах нет                                                                     |
| `alembic upgrade head → downgrade base → upgrade head → check` | Успешно на отдельной SQLite БД. Отличий от ORM-модели нет                                  |
| Проверка сгенерированного OpenAPI                              | Все 6 операций, частичный PATCH с корректной схемой обязательности и публичные поля ответа |
| `uv sync --locked --offline`                                   | Lock-файл актуален, 39 установленных пакетов проверены. Источник внешних пакетов — PyPI    |

Проверки API проходят через FastAPI, DI-контейнер, слой сценариев, SQLAlchemy и файловую SQLite с миграциями. Покрыты CRUD, сохранение между экземплярами приложения, конфликт GitLab ID, успешная синхронизация, ошибки и таймаут GitLab. Тесты конкурентного PATCH и DELETE проверяют, что ответ GitLab, полученный по старому снимку, не перезаписывает более позднее изменение.

В ходе прогона путь для временных БД тестов перенесён в локальную `.checks/` и создан его родительский каталог. Статические проверки выявили замечания к типам и импортам. При первом запуске Alembic выявилась отсутствующая зависимость асинхронного SQLAlchemy, после чего добавлен extra `sqlalchemy[asyncio]` и пересобран lock-файл. Настроенное зеркало пакетов сначала не разрешалось по DNS и позднее влияло на выбор источника зависимостей. Зависимости получены с PyPI в вызове без локальных переопределений индексов.

Ставки GPT-6.2 Sol за 1 млн токенов в USD — 2,00 за обычный вход, 0,10 за кэшированный вход и 10,00 за выход. Кэш входит во входные токены, рассуждения входят в выходные. [Карточка модели и тариф OpenAI](https://developers.openai.com/api/docs/models/gpt-6.2-sol).

`(171 693 × 2,00 + 2 700 672 × 0,10 + 20 480 × 10,00) / 1 000 000 = 0,8182532 USD`.

Для запросов свыше 272 000 входных токенов OpenAI применяет ставки 4,00, 0,20 и 15,00 USD соответственно. В отчёте доступны агрегаты по этапам, поэтому проверить порог для каждого запроса по ним нельзя. При пересчёте всего снимка по длинноконтекстным ставкам верхняя граница той же оценки составила бы 1,5341064 USD. [Карточка модели и тариф OpenAI](https://developers.openai.com/api/docs/models/gpt-6.2-sol).

## Экономика решения

- **Разработка.** 94,0% входных токенов пришлись на чтение кэша. При оплате всего входа по обычной короткоконтекстной ставке оценка составила бы 5,949530 USD. По этой модели расчёта кэш снизил стоимость примерно на 5,13 USD, или на 86,2%. Затраты на ручную проверку и сопровождение не измерялись.
- **Сравнение прогонов.** По общей ставке модель оценивается в 0,8183 USD с DevBook и 0,2154 USD без DevBook. Это разница около 0,60 USD и отношение около 3,8 раза. Снимки содержат 2 892 845 и 338 568 токенов соответственно. Прогон с DevBook включает чтение 12 документов, более широкий набор проверок и работу с миграциями и зависимостями. Границы снимков различаются по учёту финального ответа, поэтому разница описывает эти два прогона и не изолирует стоимость самого DevBook. [Отчёт прогона без DevBook](../without-devbook/RUN_REPORT.md).
- **Эксплуатация.** Сервис запускается на Python с Uvicorn и файловой SQLite. Он не вызывает модели и не расходует токены OpenAI при обработке запросов. Основные статьи затрат — хостинг, диск, резервные копии и сопровождение. Зафиксированные зависимости, миграции Alembic и проверки увеличивают объём обслуживаемого стека и дают проверяемый процесс развёртывания и обновления схемы. Для денежной оценки нужны тариф хоста, объём данных и трудозатраты.
- **Нагрузка.** CRUD обслуживается локально. Для синхронизации существующего проекта при настроенном токене выполняется одна попытка запроса к GitLab. Ежедневная синхронизация 100 проектов за 30 дней даёт около 3 000 запросов. Для оценки ресурсов нужны частота синхронизации, размер списка проектов и доля конкурентных записей. Листинг возвращает весь список, а записи SQLite конкурируют за блокировку.

На этапе проверки тестовые инструменты подтвердили контракты, типы и миграцию.                                                                                                                       |
| SPEC оставляет открытыми выбор БД, правила PATCH и уникальность GitLab ID     | Выбрана файловая SQLite для небольшого односервисного реестра. | Не были предоставлены тестовый проект GitLab и токен                          | HTTP-заглушки проверяют URL, заголовок, ответ, ошибки и общий таймаут. | Производственные требования к нагрузке, трассировке и развертыванию не заданы | Для небольшого сервиса выбраны одиночная попытка sync, стандартное логирование и явная миграция перед запуском. | Starlette TestClient предупреждает о совместимости с HTTPX                    | Предупреждение относится к тестовому клиенту. 31 тест проходит с зафиксированными зависимостями.
